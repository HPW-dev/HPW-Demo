# Исходники игры

| папка | чё внутри |
| --- | --- |
| engine | Код движка, рулит графоном, ресурсами, звуком и физикой. Ничего платформозависимого. Функции отсюда используются в _game_. |
| game | Код логики игры - уровни, противники, игрок, способности. |
| host | Разные порты инпута и рендереров. |
| plugin | .dll/.so плагины на звук и графон. |

_pch.hpp_ - самые частые хедеры. Нужен для ускорения билда.
