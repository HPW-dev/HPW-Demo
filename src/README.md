# Исходники игры
В папке _src_ лежит _main.cpp_ и вот это всё:

| папка | чё внутри |
| --- | --- |
| port | системные окна, инпут, рендер, звук и прочее платформозависимое. |
| game | логика игры - уровни, противники, игрок, способности. Ничего про рендер в текстуру OpenGL и никаких системных вызовов тут нет - юзает _port_ и _engine_. |
| engine | рулит графоном, ресурсами, звуком и физикой. Ничего связанного с системой напрямую, только через _port_. |
| util | общий код, его юзают все выше. |

_pch.hpp_ - самые частые хедеры. Нужен для ускорения билда.
