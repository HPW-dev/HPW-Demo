Описание файлов билдера:
- корень игры/build ... отсюда рулится сборка игры и прочего.
- utils ............... доп помошники, типа версия игры или пустые переменные среды.
- ui .................. цветной текст, галочки.
- info ................ лог билда.
- builder ............. сборщик и контроль зависимостей.
- args ................ все аргументы запуска и парсер аргументов.

io:
- clear ...... функции для очистки от файлов билда и прочего.
- fs ......... работа с папками
- hash ....... хэши файлов
- platform ... инфа о системе

distr:
- compiler ... инфа о компиляторе и прочая его специфика
